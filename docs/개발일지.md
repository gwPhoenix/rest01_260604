## 3. 히어로 영역 JavaScript 효과

### 3-1. Canvas 파티클
- 70개 보라색 점이 배경에서 천천히 부유
- `requestAnimationFrame` 루프, 정규화 좌표(0~1) → canvas 크기에 독립적

### 3-2. 마우스 패럴랙스
- `mousemove` 이벤트로 배경 그라디언트가 마우스 방향으로 최대 ±22px 이동
- 선형 보간(lerp factor 0.06)으로 부드러운 추적

### 3-3. 타이핑 효과 (Typewriter)
- 4가지 소개 문구를 타이핑 → 2.2초 대기 → 삭제 → 반복
- 타이핑 속도 55ms/글자, 삭제 속도 28ms/글자
- CSS `@keyframes blink`로 커서 깜빡임 구현

## 4. GSAP MotionPath SVG 애니메이션

히어로 오른쪽에 SVG path를 따라 rect가 움직이는 장식 애니메이션 추가.

```
라이브러리: GSAP 3.12.5 (CDN)
플러그인: MotionPathPlugin
경로: M50.5 50.5h50v50s... (S자형 무한 곡선)
duration: 18s / repeat: -1 / ease: none
rect 효과: drop-shadow(오렌지~핑크 글로우)
```

- 반응형: 900px 이하에서 숨김 처리
- 히어로 진입 시 fadeIn 애니메이션(1.2s delay)

## 5. 컬러 팔레트 시스템

### 컬러 구조
| 역할 | 변수 | 설명 |
|------|------|------|
| 주 컬러 | `--clr-accent` | 팔레트별 다크 계열 |
| 보조 컬러 | `--clr-accent-secondary` | 주 컬러 50% 투명도 |
| 이벤트 컬러 | `--clr-event` | 다크모드 `#ffd600` / 라이트모드 `#8b5e00` |

### 5가지 팔레트
| # | 이름 | 다크 모드 | 라이트 모드 |
|---|------|-----------|-------------|
| 1 | 퍼플 | `#4a2bb8` / `#a599f7` | 연보라 배경 |
| 2 | 블루 | `#1e4db7` / `#5b9cf6` | 연블루 배경 |
| 3 | 그린 | `#1c6b40` / `#5bc98a` | 연그린 배경 |
| 4 | 레드 | `#8b1a1a` / `#f87171` | 연핑크 배경 |
| 5 | 오렌지 | `#7c3300` / `#fb923c` | 연크림 배경 |

### 구현 방식
- CSS `data-palette` 속성 + `:root[data-palette="..."]` 오버라이드
- 다크/라이트 모드: `data-theme` 속성 토글
- `localStorage`로 선택 상태 영구 저장
- 팔레트 스위처 UI: 화면 우하단 고정, 원형 스와치 5개 + ☀️/🌙 토글

### 접근성 (WCAG 대비비)
- 본문 텍스트 대비비: ~18:1 ✓
- 이벤트 컬러(옐로우) on 다크 배경: ~15:1 ✓
- 버튼 흰 텍스트 on 액센트 배경: 6.8:1 이상 ✓
